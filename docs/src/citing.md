# Citing BondGraphToolkit

If you use `BondGraphToolkit.jl` in your work, please cite the software. The repository's [CITATION.cff](https://github.com/felipecastrotc/BondGraphToolkit.jl/blob/main/CITATION.cff) has the reference, and GitHub's *Cite this repository* button gives it as BibTeX or APA:

```bibtex
@software{BondGraphToolkit,
  author  = {de Castro Teixeira Carvalho, Felipe},
  title   = {BondGraphToolkit.jl: bond graphs as ModelingToolkit systems},
  version = {0.3.0},
  year    = {2026},
  url     = {https://github.com/felipecastrotc/BondGraphToolkit.jl}
}
```
