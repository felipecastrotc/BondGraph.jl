Equations and LaTeX

The source files for all examples can be found in /examples.

A bond-graph model is an MTK system, so its equations are available as for any MTK model. bgequations returns them in terms of the states only, with the names you choose, ready for a report or a paper through latexify.

using BondGraphToolkit
using BondGraphToolkit.ModelingToolkit: t_nounits as t, D_nounits as D
using OrdinaryDiffEqTsit5

A mass–spring–damper driven by a force: the source's bond points into the 1-junction, the element bonds point out of it.

@named F = Se(sin(t))
@named m = Inertia(I = 1.0)
@named k = Compliance(C = 1.0)
@named b = Resistance(R = 0.5)
@named model = Junction1(F => :pout, m, k, b)

\[ \begin{align} 0 &= \mathrm{connect}\left( F_{+}pout, core_{+}p1 \right) \\ 0 &= \mathrm{connect}\left( m_{+}power, core_{+}p2 \right) \\ 0 &= \mathrm{connect}\left( k_{+}power, core_{+}p3 \right) \\ 0 &= \mathrm{connect}\left( b_{+}power, core_{+}p4 \right) \\ - \mathtt{core.p2.f}\left( t \right) &= \mathtt{core.p1.f}\left( t \right) \\ - \mathtt{core.p3.f}\left( t \right) &= \mathtt{core.p1.f}\left( t \right) \\ - \mathtt{core.p4.f}\left( t \right) &= \mathtt{core.p1.f}\left( t \right) \\ 0 &= \mathtt{core.p1.e}\left( t \right) - \mathtt{core.p2.e}\left( t \right) - \mathtt{core.p3.e}\left( t \right) - \mathtt{core.p4.e}\left( t \right) \\ \mathtt{F.e}\left( t \right) &= \mathtt{F.power.e}\left( t \right) \\ \mathtt{F.pout.e}\left( t \right) &= \mathtt{F.power.e}\left( t \right) \\ \mathtt{F.f}\left( t \right) &= - \mathtt{F.pout.f}\left( t \right) + \mathtt{F.power.f}\left( t \right) \\ \mathtt{F.e}\left( t \right) &= \sin\left( t \right) \\ \frac{\mathrm{d}\mathtt{m.p}\left( t \right)}{\mathrm{d}t} &= \mathtt{m.e}\left( t \right) \\ \mathtt{m.e}\left( t \right) &= \mathtt{m.power.e}\left( t \right) \\ \mathtt{m.pout.e}\left( t \right) &= \mathtt{m.power.e}\left( t \right) \\ \mathtt{m.f}\left( t \right) &= - \mathtt{m.pout.f}\left( t \right) + \mathtt{m.power.f}\left( t \right) \\ \mathtt{m.f}\left( t \right) &= \frac{\mathtt{m.p}\left( t \right)}{\mathtt{m.I}} \\ \frac{\mathrm{d}\mathtt{k.q}\left( t \right)}{\mathrm{d}t} &= \mathtt{k.f}\left( t \right) \\ \mathtt{k.e}\left( t \right) &= \mathtt{k.power.e}\left( t \right) \\ \mathtt{k.pout.e}\left( t \right) &= \mathtt{k.power.e}\left( t \right) \\ \mathtt{k.f}\left( t \right) &= - \mathtt{k.pout.f}\left( t \right) + \mathtt{k.power.f}\left( t \right) \\ \mathtt{k.e}\left( t \right) &= \frac{\mathtt{k.q}\left( t \right)}{\mathtt{k.C}} \\ \mathtt{b.e}\left( t \right) &= \mathtt{b.power.e}\left( t \right) \\ \mathtt{b.pout.e}\left( t \right) &= \mathtt{b.power.e}\left( t \right) \\ \mathtt{b.f}\left( t \right) &= - \mathtt{b.pout.f}\left( t \right) + \mathtt{b.power.f}\left( t \right) \\ \mathtt{b.e}\left( t \right) &= \mathtt{b.R} ~ \mathtt{b.f}\left( t \right) \end{align} \]

The equations in terms of the states, the spring's displacement q and the mass's momentum p. Namespaced names such as k₊q show which element each variable belongs to:

bgequations(model)

\[ \begin{align} \frac{\mathrm{d}\mathtt{m.p}\left( t \right)}{\mathrm{d}t} &= \sin\left( t \right) + \frac{ - \mathtt{k.q}\left( t \right)}{\mathtt{k.C}} + \frac{ - \mathtt{b.R} ~ \mathtt{m.p}\left( t \right)}{\mathtt{m.I}} \\ \frac{\mathrm{d}\mathtt{k.q}\left( t \right)}{\mathrm{d}t} &= \frac{\mathtt{m.p}\left( t \right)}{\mathtt{m.I}} \end{align} \]

Renaming

Map any variable or parameter to the name to show. Renaming a variable renames its derivative too, unless the derivative has its own entry, here ẋ for the velocity of the spring's end:

@variables x(t) ẋ(t) p(t)
@parameters M c C
eqs = bgequations(model; rename = Dict(model.k.q => x, D(model.k.q) => ẋ, model.m.p => p,
                                        model.m.I => M, model.b.R => c, model.k.C => C))

\[ \begin{align} \frac{\mathrm{d}p\left( t \right)}{\mathrm{d}t} &= \sin\left( t \right) + \frac{ - x\left( t \right)}{C} + \frac{ - c ~ p\left( t \right)}{M} \\ \dot{x}\left( t \right) &= \frac{p\left( t \right)}{M} \end{align} \]

LaTeX

latexify(eqs)

\begin{align} \frac{\mathrm{d}p\left( t \right)}{\mathrm{d}t} &= \sin\left( t \right) + \frac{ - x\left( t \right)}{C} + \frac{ - c ~ p\left( t \right)}{M} \ \dot{x}\left( t \right) &= \frac{p\left( t \right)}{M} \end{align}

Renamed variables in a solution

bgequations only changes how the equations are shown. To read a renamed variable from a solution, add an alias equation to the model; MTK keeps it as an observed variable:

@named aliased = System([x ~ model.k.q], t; systems = [model])
sol = solve(ODEProblem(mtkcompile(aliased), [], (0.0, 10.0)), Tsit5())
sol[x][end]
1.5084125238241186

A solution can be indexed by one variable at a time. To plot or compute a product such as the power e⋅f on a bond, sample each factor and multiply:

power = sol[model.b.e] .* sol[model.b.f]
power[end]
0.545891769449127
