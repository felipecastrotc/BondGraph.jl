# Security policy

BondGraphToolkit.jl is a modeling library; it runs no services and handles no credentials. If you still find a security issue, for example in the way it calls Graphviz, please report it privately through [GitHub's private vulnerability reporting](https://github.com/felipecastrotc/BondGraph.jl/security/advisories/new) rather than in a public issue.

Fixes go into the latest release only.
